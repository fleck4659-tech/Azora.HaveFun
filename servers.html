How global user tracking works

Your site on GitHub Pages is static — phones and computers cannot share localStorage. Real accounts (not guests) are counted using a free Firebase Realtime Database.

  1. Go to https://console.firebase.google.com and create a project (e.g. azora-havefun).
  2. Build → Realtime Database → Create database → start in test mode (for now).
  3. Copy the database URL, like https://azora-havefun-default-rtdb.firebaseio.com
  4. Open script.js on the site and set:
    firebaseUrl: "https://YOUR-PROJECT-default-rtdb.firebaseio.com" inside AZORA_CLOUD near the top.
  5. Also paste the same URL into the box below (saved only on this staff browser).
  6. Publish/upload the updated script.js to GitHub Pages.

Guests are never uploaded. Only username + User ID + join time are stored in the cloud — not passwords.
